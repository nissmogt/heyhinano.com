# heyhinano.com

Standalone GitHub Pages site for Hinano Akiyama (heyhinano.com).

Single-page portfolio in `index.html`, no build step.

- Design: warm off-white, hairline rules, Helvetica, radiating-line hero motif.
- Work is grouped by year; the fixed rail on the right (bottom bar on phones) jumps between years and highlights the year in view.
- Logos live in `assets/logos` (press), `assets/clients-real` (clients) and `assets/logos-2026` (2026 additions).
- `assets/logos-2026/foamstars-tile.svg` is a placeholder tile; replace with official Foamstars key art when available.
